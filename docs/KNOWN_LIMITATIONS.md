# Known Limitations / Future Improvements

## Current v1 limits

1. The homepage is significantly stronger than the legacy site, but it is still information-dense on mobile.
2. The 3D experience is integrated, branded, and safer from a content-fidelity perspective, but it is still visually closer to a high-quality prototype than a fully custom modeled rover pipeline.
3. The 3D build retains procedural geometry rather than a dedicated optimized DAWN GLB asset.
4. Some public role labels are inconsistent in capitalization because the official roster itself is inconsistent; the rebuild preserves those names conservatively.

## Recommended next upgrades

1. Replace the procedural rover shell with a verified DAWN model and hotspot-authenticated annotations.
2. Add a dedicated sponsor inquiry page and downloadable sponsor deck.
3. Create a structured data source maintained by the team (JSON/Sheet/CMS) to replace manual public-copy extraction.
4. Add a filtered team directory by department.
5. Convert more long sections into richer editorial layouts instead of card grids.
